# Interest-Calculator
# 📊 Interest Calculator (Python + Tkinter)

A modern and interactive desktop application to calculate **Simple Interest** and **Compound Interest**.  
Built using **Python** and **Tkinter**, this tool provides a clear, visually appealing interface for users to easily calculate interest and total amounts.

---

## 🚀 Features

- **Simple Interest** and **Compound Interest** calculation
- Input fields for:
  - Principal amount
  - Annual interest rate
  - Time (in years)
  - Frequency of compounding (for Compound Interest)
- **Real-time result display** with a clean, large area for results
- Beautiful **GUI** with modern styling and spacing
- Error handling for invalid inputs

---

## 🖥️ Tech Stack

- **Programming Language**: Python 3.x
- **GUI Library**: Tkinter (Standard Python Library)
  
No external libraries are required, making it easy to run anywhere with Python.

---

## 📦 Requirements

- Python 3.x (Download from [python.org](https://www.python.org/downloads/))
- Tkinter (pre-installed with Python)
